# 테스트 실행 기록 양식

이 파일은 미실행 양식이다. 실제 결과는 `Logs/YYYY-MM-DD_subject.md`에 저장한다.

## 실행 정보

- 날짜·시간 KST / 실행자·제공 자료 여부:
- 테스트 목적 / F-ID·T-ID·Issue·PR:
- IR 문서·회차 / 검증 실행자·검토자 / 실제 개발자 지적·최종 판단(없으면 미확인):
- commit / dirty 상태 / 최초 커밋 전 기준 파일:
- Unity·패키지 / Editor·에뮬레이터·Android 실기기 구분:
- 빌드 버전·코드·APK SHA-256 / Development·Profiler·로그 설정:
- 기기·OS·화면·품질·네트워크(필요 시):

## 절차와 결과

- 사전 조건·데이터·씬:
- 재현 입력·횟수·실행 기간:

| T-ID | 절차 | 기대 결과 | 실제 관찰 | PASS/FAIL/NOT RUN/N/A | 자료·로그 태그 |
|---|---|---|---|---|---|

## 결함·후속

- FAIL의 심각도·발생 횟수/시도 횟수·Issue:
- NOT RUN의 이유·다음 실행자/조건:
- 수정 PR / 같은 조건 재검증 기록:
- 남은 위험·검증 범위:

이전 실패 결과는 유지하고 새 실행으로 연결한다. 영상을 첨부하면 장면·시간대를 적고 개인정보를 정제한다.
