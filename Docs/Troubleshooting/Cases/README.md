- 2026-11-13 PoC 플레이 테스트 문제와 수정 (공개 제외): 출입창 반복·주민 방문 누락·UI 정지 등, 밸런스/사용성 및 기능 보완 분류. 기존 Editor 검사·개발자 플레이 확인과 미실행 범위를 포함한다.
