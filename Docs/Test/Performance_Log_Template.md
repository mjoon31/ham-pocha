# 성능 측정 기록 양식

상태: 미실행 양식. 실제 측정은 성능 규칙 (공개 제외)을 따른다.

## 조건

- 날짜·실행자 / F-ID·ADR·Issue / 비교 전후 commit:
- APK 해시·버전·빌드 코드 / dirty:
- Development·Profiler·Deep Profile·로그 / 백엔드·CPU 아키텍처·그래픽 API:
- 모델·SoC·RAM·Android·화면·주사율·해상도·품질:
- 밝기·충전·시작 배터리·실내 조건·이전 실행/냉각 조건:
- 장면·입력 시나리오 / 워밍업·측정 기간·반복 횟수:
- 수집 도구·샘플 방식·미측정 항목:

## 기준과 측정

| 항목 | 승인된 기준·ADR | 변경 전 | 변경 후 | 판정·한계 |
|---|---|---|---|---|
| FPS·프레임 시간 p95/p99 | 미정 | 미측정 | 미측정 | NOT RUN |
| 긴 프레임·기간별 변화 | 미정 | 미측정 | 미측정 | NOT RUN |
| CPU main/render·GPU | 미정 | 미측정 | 미측정 | NOT RUN |
| 메모리 기준·피크·종료 후 | 미정 | 미측정 | 미측정 | NOT RUN |
| GC 할당·수집 정지 | 미정 | 미측정 | 미측정 | NOT RUN |
| 발열·thermal 상태 | 미정 | 미측정 | 미측정 | NOT RUN |
| 배터리 변화·측정 기간 | 미정 | 미측정 | 미측정 | NOT RUN |
| 시작·로딩·입력 반응 | 미정 | 미측정 | 미측정 | NOT RUN |

전후 비교가 아닌 첫 기준선이면 비교 열을 N/A로 두고 단일 측정값을 적는다. 관찰된 배터리 변화는 동일 조건의 비교 자료이며 다른 기기의 사용 시간으로 일반화하지 않는다.
