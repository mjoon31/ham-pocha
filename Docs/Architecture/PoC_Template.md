- 관련 ADR·F-ID·Issue / 담당·실행일:
- 검증할 가설·가장 큰 불확실성:
- 필요한 최소 코드·장면·기기·패키지:
- 실험 범위·시간 상한·중단 조건:

| 검증 질문 | 성공 기준 | 실패 기준 | 절차 | 실제 값 | PASS/FAIL/NOT RUN | 로그·자료 |
|---|---|---|---|---|---|---|
