## 개발자 요청·이미 정한 조건

3D 탑뷰 또는 참고 1과 비슷한 사선뷰, 귀여운 캐릭터·배경, 캐주얼. 저장 없는 협동 또는 단판 솔로를 비교한다. 참고 2 같은 성장형은 자체 DB 없이 무료로 저장하는 방식을 조사한다. 참고 영상의 장르·감각을 반영하되 복제하지 않고 장르가 다른 3안을 충분한 설명으로 제시한다. 문서 확정보다 게임 경험 설명을 우선한다.

## 회차 1 — AI 조사·제안

- 기존 조사·기획 규칙을 확인하고 모바일 스토어 원문·커뮤니티를 조사했다. 총 24개 의견을 요약했으며 중복 렌더링·개발자 답변·홍보는 제외했다.
- YouTube 텍스트 조회 실패 후 브라우저로 두 영상의 제목과 일부 플레이 화면을 확인했다. 처음 게임 제목을 질문했으나 브라우저에서 해결되어 추가 답변이 불필요함을 알렸다.
- 참고 1: Little Cheese Works. 작은 캐릭터·공간 크기 대비·협동을 참고한다. 참고 2: 낚시왕 키우기. 낚시·수집·성장 만족을 참고한다.
- AI 후보: A 장난감 야간 수리대(2인 협동), B 구름바다 낚시 소풍(단판 낚시 탐험), C 피크닉 길잡이(솔로 공간 퍼즐).
- AI 추천은 B이며 최종 선정이 아니다. A는 실제 2대 접속·동기화, B는 한 판 초기화 수용, C는 규칙·경로 조작을 먼저 검증한다.
- Google Saved Games는 자체 DB 없는 진행 파일 저장 대안이다. 저장 데이터 비과금과 Play Console 등록비·연동 작업을 구분했다. SDK 설치·계정 생성·기술 채택은 하지 않았다.

## 회차 2 — 출처 확인 가능성 보강

- 개발자 지적: 리뷰를 실제 근거로 확인할 수 있도록 출처 링크 등을 제시하도록 요청했다.
- AI 제안·반영: 기존 24개 R-ID에 원문 링크·공개 표시 이름·게시일·짧은 검색 문구를 일대일로 붙이고 링크 종류·접근 한계를 구분한다. 새 의견을 수집한 것으로 집계하지 않는다.
- 실제 수정자: AI, 경위 `directed`. 개발자가 직접 파일을 수정한 사실은 확인되지 않았다. commit/push는 수행하지 않았다.
- 재확인: 스토어 7개 언어별 페이지에서 리뷰 표시 이름·날짜·내용을 대조했다. Reddit 개별 댓글 주소 3개를 원문 링크에서 확보했으나 직접 조회는 실패하여 이전에 본문을 확인한 상위 글을 함께 연결했다.
- 해석 보완: Spaceteam의 현재 업데이트에는 접속 문제 수정 안내가 있다. 과거 리뷰 불만을 현재 미해결 결함으로 단정하지 않도록 원자료·시장 보고서에 반영했다.
- 검증: PASS — 변경/신규 문서 5개·원자료와 일치하는 R-ID 24개·내부 링크 19개·웹 링크 항목 37개·표 구조/인코딩/용어 확인. 웹 링크 항목 수는 개별 URL의 접근 성공 건수가 아니다. 실제 게임 결함 재현·개발자 최종 판단은 미실행/미기록이다.
- 과정 원본: [리뷰 출처 확인표](../../Research/Review_Source_Index.md). 별도 중복 이슈는 생성하지 않았다.

## 회차 3 — 국내 조사·Steam 참고·후보 6안으로 재검토

- 개발자 수정 지시: 귀여운 캐주얼을 고정하고 협동 3개·솔로 3개로 다양화한다. 탐험·파밍 가능, 리뷰·시장조사는 국내만 사용한다.
- 추가 방향: Steam 출시/출시 예정 게임도 구조 참고한다. Deep Blue Sushi처럼 외부 사냥/파밍→가공·조리→임무/스테이지 완료를 작은 모바일 게임으로 변형할 수 있다. 음식은 필수가 아니다.
- AI 제안: C1 숲속 원정 도시락단, C2 조개섬 장난감 구조소, C3 별사탕 캠프 방어대, S1 주머니 섬의 마지막 등대, S2 작은 마녀의 출장 약방, S3 햄포차 (Ham Pocha). 추천은 작은 완성 범위의 S2, 탐험·조리 감각은 C1/S3이며 최종 선정은 아니다.
- 실제 수행: 한국 스토어 한국어 리뷰 20건·6종을 대조하고 Steam 한국어 공식 상품 6종의 구조·출시 상태를 확인했다. Steam 개별 한국어 후기·Google Play 한국어 리뷰는 충분히 확보하지 못한 상태를 표시했다.
- 수정자·경위: AI가 개발자 지적·방향을 반영한 directed 작업이다. 개발자 직접 파일 수정·최종 후보 선택은 확인되지 않았다. commit/push 없음.
- 변경: 현재 시장 보고서·후보 비교를 갱신, 한국 리뷰 확인표 추가, 초기 해외 조사와 3안은 이력으로 보존·현재 선정 근거에서 제외. 연구 규칙·상태·색인·접근 기록에 범위 반영.
- 검증: AI PowerShell 정적 검사 PASS — 변경/신규 문서 15개, 내부 링크 110개, 한국 리뷰 행 20개, 협동 3개·솔로 3개, 표 구조·인코딩·공개 용어 확인. 외부 URL 접근 성공 수나 게임 실행 결과가 아니다. 상품 설명과 실제 플레이를 구분한다.
- 개발자 테스트·검수·최종 결정: 미기록. Unity/Android/Steam 게임 실행: NOT RUN. 기능·패키지·씬·설정 변경 없음.
