## 1. 개발자 요청

이 채팅에서 개발자가 다음 기준으로 기존 규칙을 고치도록 요청했다.

- AI에 지시해 수행한 작업, 개발자가 결정·지적해서 고친 작업, 개발자가 직접 수정한 작업을 Git 커밋에서 구분한다.
- `AI에 지시 → AI 제안 → 개발자 결정 → 테스트·검수 → 최종 결정 또는 이슈로 인한 재수정` 과정을 별도 폴더에 문서화한다.
- 이번 범위는 로컬 운영 문서·양식 정비다. 실제 commit/push·원격 설정·게임 구현은 포함하지 않는다.

완료 조건: 커밋 Summary/본문에서 변경 경위·실제 수정자를 구분하고, 별도 과정 양식·실제 기록과 PR/테스트 연결을 제공하며 문서 정적 검사를 통과한다.

## 2. 진행 — 회차 1

### AI 제안

- 기존 `type(scope)`를 유지하고 `[ai]`, `[directed]`, `[manual]`, `[mixed]`, `[review]` 태그로 변경 경위를 표시한다.
- 실제 수정자·개발자 판단·검증 실행자는 본문에서 따로 적는다. 개발자 지적을 AI가 반영한 것을 개발자 직접 수정으로 기록하지 않는다.
- `Docs/Issue_Records/Records/`에 한 작업의 회차를 누적하고 기존 ADR·Test Log·심층 분석은 링크한다.
- 개별 커밋 보존을 기본으로 하고 Squash 시 구분 손실과 본문 보존 조건을 정한다.

### 개발자 결정·지적

- 확인된 결정: 작업 경위를 분리하고 요청부터 최종 판단/재수정까지 별도 문서로 남기라는 이번 사용자 지시.
- AI가 선택한 세부: 태그 이름·IR-ID·파일 구조·본문 필드·병합 시 보존 방법.
- 세부 제안에 대한 후속 채택/반려 발언: 아직 없음. AI가 최종 승인으로 기록하지 않는다.
