## 회차5 — Editor 입력 불가/커스텀 UI CanvasRenderer 누락

개발자가 현재 Editor Play의 콘솔 오류/조작 불가를 보고하고 확인을 요청했다. AI가 Editor.log에서 InputMask의 `MissingComponentException`211건을 확인했다. 스택은 GraphicRaycaster.Raycast→EventSystem.RaycastAll→InputSystemUIInputModule.Process에서 중단되며 확인 버튼 입력이 전달되지 않아 튜토리얼 이동 잠금 해제도 진행되지 않는 경로다. 기존 계정 저장/클라우드 성공 로그와 이 입력 예외를 구분했다.

수정:TutorialShade.cs·ProgressRing.cs에 `[RequireComponent(typeof(CanvasRenderer))]`를 추가해 AddComponent 때 CanvasRenderer가 먼저 연결되도록 했다. 동작/수치·씬/저장/계정/서버는 이번 회차에서 편집하지 않았다. 개발자 작업내용은 Editor Play 실행·오류/조작 불가 보고이며, 실제 코드 수정은 AI다.
