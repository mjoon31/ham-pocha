# 플레이테스트와 사용자 피드백 양식

상태: 미실행 양식. 실제 참여·응답만 기록한다.

- 빌드·commit·APK 해시 / 날짜·기기·OS:
- 익명 참여 수 / 관찰 방식·플레이 횟수·기간:
- 사전 설명 범위 / 확인하려는 핵심 질문:

## 질문

1. 조작법·목표를 얼마나 쉽게 이해했는가? 1~5점과 이유.
2. 가장 재미있었던 행동과 그 순간은 무엇인가?
3. 불편·혼란·진행 불가가 발생한 순간은 무엇인가?
4. 다시 플레이하고 싶은가? 이유는 무엇인가?
5. 터치·가독성·소리·프레임·발열 문제는 있었는가?
6. 바꾸고 싶은 기능은 무엇인가?

## 실제 응답과 조치

| 익명 항목 | 실제 의견 요약 | 관찰·재현 | AI 해석 | 반복 빈도/분모·심각도·비용 | 개발자 결정·이유 | 수정·재검증 |
|---|---|---|---|---|---|---|

이름·연락처·계정·기기 고유 ID를 수집하지 않는다. 공개할 영상·음성은 대상자의 동의와 개발자 공개 승인을 확인한다. 적은 표본의 점수를 전체 이용자 만족도로 표현하지 않는다.
