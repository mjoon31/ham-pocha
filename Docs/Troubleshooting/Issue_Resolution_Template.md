# 문제 해결 기록 양식

실제 사례는 `Cases/YYYY-MM-DD_subject.md`로 저장한다. 이 파일은 사례가 아니다.

- 제목: 실제 발생한 증상·개선 대상
- 날짜·상태 / Issue·PR·commit·ADR:

## 문제와 재현

- 기대 결과 / 실제 결과·사용자 영향:
- 기기·OS·Unity·빌드·재현 절차:
- 최초 관찰·빈도·로그 태그·자료:

## 원인 분석

| 가설 | 확인·반증 방법 | 실제 관찰 | 결론 |
|---|---|---|---|

확인한 원인과 미확인 가설을 구분한다. 해결되지 않았으면 원인 확정으로 쓰지 않는다.

## 대안과 결정

| 대안 | 효과·비용·부작용 | AI 제안 내용 | 개발자 채택/반려·이유 |
|---|---|---|---|

## 수정·검증

- 실제 변경 파일·설정·PR:
- 변경 전후 동일 조건 테스트·수치 / Test Log:
- 실행자·기여 구분 / 결과 PASS·FAIL·NOT RUN:
- 미해결 위험·재발 방지·후속 Issue:

공개 시 실제 개발 문제·판단·변경·검증 흐름으로 요약하고 공개 검수 (공개 제외)를 거친다.
